# HPI-Net

This repository contains the official implementation of **HPI-Net**:  
**HPI-Net: A Hierarchical and Progressive Interaction Network for High-Resolution Satellite Stereo Images Disparity Estimation**  
**Authors**: Junxiao Li, Xiangrong Zhang, Chaowei Fang, Xu Tang and Huiyu Zhou

> The complete codebase, including pretrained weights, will be released upon acceptance of the paper.
