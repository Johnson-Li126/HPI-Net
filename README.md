# HPI-Net

**Authors**: Li, Junxiao and Zhang, Xiangrong and Fang, Chaowei and Li, Zhenyu and Tang, Xu and Zhou, Huiyu and Jiao, Lichen

> The complete codebase, including pretrained weights, will be released upon acceptance of the paper.
